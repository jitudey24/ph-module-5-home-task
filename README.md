# New Year Celebration Landing Page

A festive landing-page practice project built with HTML and CSS. The page introduces a New Year celebration with a hero banner and promotional content.

## Features
- New Year celebration hero banner
- Promotional holiday offer section
- Custom layout and styling
- Font Awesome icon support

## Technologies
- HTML5
- CSS3
- Font Awesome

## Run Locally
1. Clone this repository.
2. Keep the stylesheet and required assets in their project folders.
3. Open `index.html` in your browser.

## Project Purpose
This project is a Programming Hero module task focused on page structure, visual hierarchy, and CSS layout.
